# Hospital-Analytics-Project
## Project Overview
- This project analyzes 20, 000 hospital and patient
records to identify trends in diseases, 
demographics, severity, geographical distribution, 
treatment, hospitalization, costs, and patient
outcomes
## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Analysis
- Data Visualization
## Key Features
- Data cleaning and preparation
- Pivot Table analysis
- Healthcare KPI analysis
- Interactive dashboard
- Disease and demographic analysis
- Severity and treatment analysis
- Location and seasonal trend analysis
## Project Objective
- To analyze hospital data and identify meaningful
trends that can support better healthcare insights
and decision-making.
